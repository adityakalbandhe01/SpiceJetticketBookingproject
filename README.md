# ✈️ SpiceJet Calendar Automation (Selenium + TestNG)

## 📌 Project Overview
This project automates the **SpiceJet flight booking calendar** to dynamically select a future date using **Java LocalDate** and Selenium WebDriver.

## 🛠 Tech Stack
- Java
- Selenium WebDriver
- TestNG
- Maven

## ✅ Key Features
- Dynamic date selection (no hard-coded dates)
- Explicit waits for stability
- TestNG annotations (@BeforeMethod, @Test, @AfterMethod)
- Assertion to verify selected date
- Clean Maven structure
